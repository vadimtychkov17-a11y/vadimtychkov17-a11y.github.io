## 🛠️ Технические особенности

*   **Современный UI/UX**: Дизайн в стиле *Liquid Glass* (матовое стекло, плавные анимации, свечения и глубина).
*   **3D-графика**: Использование библиотеки **Three.js** для создания реалистичного неба, воды, теней и пост-обработки (Bloom) прямо в браузере.
*   **Аудио-синтез**: Генерация звуков с нуля через **Web Audio API** (без использования сторонних mp3-файлов в коде).
*   **Адаптивность**: Полная поддержка мобильных устройств, планшетов и ПК (включая тач-управление и виртуальные джойстики).
*   **Оптимизация**: Плавные 60 FPS даже на слабых устройствах благодаря грамотному рендерингу и предотвращению утечек памяти.

## 💻 Как запустить локально

Если ты хочешь запустить проекты не через GitHub Pages, а на своем компьютере:

1. Скачай репозиторий (или отдельные папки с проектами).
2. Для запуска игр/визуализаторов **недостаточно просто открыть HTML-файл** (браузер заблокирует загрузку аудио и текстур). Используй локальный сервер:
   * Через VS Code: установи расширение **Live Server** и нажми "Go Live".
   * Через Python: открой терминал в папке с проектом и введи `python -m http.server 8000`.
