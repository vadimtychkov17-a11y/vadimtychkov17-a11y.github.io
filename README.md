## 🚀 О проекте

Добро пожаловать в **vindim** — коллекцию экспериментов с графикой, физикой и звуком прямо в браузере. Здесь нет тяжёлых фреймворков, только чистый код, магия WebGL и немного безумия.

> ⚠️ **Важно:** Все проекты созданы с помощью искусственного интеллекта.  
> **vindim** — это выдуманная корпорация, которой не существует в реальном мире.

## ⚡ Быстрый старт

Все проекты работают прямо в браузере. Вы можете просто открыть `index.html` в корне репозитория.

Если вы хотите запустить проект локально (например, для доработки кода):

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vadimtychkov17-a11y/vadimtychkov17-a11y.github.io.git
   ```
   
2. Перейдите в папку проекта:
   ```bash
   cd vadimtychkov17-a11y.github.io
   ```
   
3. Откройте `index.html` в вашем браузере или запустите локальный сервер:
   ```bash
   python -m http.server 8000
   ```
